# J2025_B

独立优化器：[实现](j2025_b.cpp) · [API](j2025_b.h)。

优化目标：单个 region 的运行时间。每个 region 独立推进状态；每次调用只执行一个配置。`N` 为初始线程上限（至少为 2 的偶数），`CLOSE` 表示连续 CPU 绑定（CONTIGUOUS）。

```c
on_each_parallel_region(R) {
    State *S = state_of(R);

    /* 1. Warm-up */
    if (S->phase == WARMUP) {
        run(R, N, CLOSE);             // 忽略本次耗时
        fibonacci_init(S, {2, 4, ..., N});
        S->phase = NT_SEARCH;
        return;
    }

    /* 2. Thread-count search: 固定连续绑定 */
    if (S->phase == NT_SEARCH) {
        nt = fibonacci_next_unmeasured(S);
        time = run_and_measure(R, nt, CLOSE);
        cache_sample(S, nt, time);
        update_fibonacci_interval(S); // 复用已测候选，缩小区间

        if (no_unmeasured_candidate(S)) {
            S->best_NT = fastest_measured_nt(S);
            S->mapping_sample = 0;
            S->phase = TM_SEARCH;
        }
        return;
    }

    /* 3. Thread mapping search: 固定所选线程数，重新测量 */
    if (S->phase == TM_SEARCH) {
        TM = (S->mapping_sample == 0) ? SCATTER : CLOSE;
        S->mapping_time[TM] = run_and_measure(R, S->best_NT, TM);

        if (++S->mapping_sample == 2) {
            S->best_TM = (S->mapping_time[CLOSE] < S->mapping_time[SCATTER])
                       ? CLOSE : SCATTER;
            S->phase = STABLE;
        }
        return;
    }

    /* 4. Stable execution */
    run(R, S->best_NT, S->best_TM);
}
```

实际执行由框架拆为 `select_cfg → HAMS.apply → 执行 region → observe`；选择和绑定在 `PARALLEL_START`，耗时反馈在 `PARALLEL_END`。
